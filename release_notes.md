## BruceIRF v4.0 Release

### New Features
- **SubGHz Music RX**: RF audio player in SubGHz menu - predefined melodies, next/prev, play/stop, volume control
- **Pablo Mode Easter Egg**: Hidden in Others menu - mango chaos with animated shapes, LEDC tones, escalating text
- **English Localization**: All UI strings in Universal IR/RF translated from Italian to English
- **Built-in IR always visible**: IR categories always shown with generic functional buttons

### Bug Fixes
- MCLK pin conflict fix on T-Embed CC1101
- Dual spectrum fix, IR Clone UX, SD dedup
