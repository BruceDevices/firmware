# Bruce Scroller

**Bluetooth-пульт для смартфона на Bruce Firmware, рассчитанный на LILYGO T-Embed CC1101 (ESP32-S3).** Поворот энкодера отправляет прокрутку колеса мыши, нажатия управляют страницами и мультимедиа.

[English](README.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md)

Bruce Scroller — небольшая модификация [Bruce Firmware](https://github.com/BruceDevices/firmware) для BLE HID-прокрутки. Она сохраняет меню и функции Bruce и добавляет режим для платы **LILYGO T-Embed CC1101 (ESP32-S3)**.

## Возможности

- Поворот энкодера отправляет события колеса мыши по Bluetooth LE.
- Один клик отправляет Volume Down, двойной — Volume Up. MangaLib может трактовать эти команды как переход вперёд и назад; результат зависит от приложения и его настроек.
- Удержание переключает пять уровней чувствительности прокрутки.
- После подключения устройство пытается переместить указатель от центра. Видимость курсора контролирует Android, поэтому он может остаться на экране.
- Экран рисуется при входе, а затем обновляются только изменившиеся строки статуса — без прежней периодической полной перерисовки.
- Остальные режимы Bruce, включая `Media Cmds`, сохранены.

Автор сообщил о проверке с MangaLib на Android-смартфоне. Модель телефона, версия Android и приложения не записаны как матрица совместимости. TikTok, Instagram Reels, YouTube Shorts и другие приложения **не проверялись**; обработка прокрутки и кнопок громкости зависит от приложения.

## Управление

| Действие | Результат |
| --- | --- |
| Поворот вправо | Прокрутка вниз |
| Поворот влево | Прокрутка вверх |
| Один клик энкодера | Volume Down; следующая страница, если приложение так настроено |
| Двойной клик | Volume Up; предыдущая страница, если приложение так настроено |
| Удержание энкодера | Переключить чувствительность от 1 до 5 |
| Боковая кнопка Back | Выйти из Bruce Scroller в Bruce |

Колесо отправляется небольшими шагами с интервалом 16 мс. Ограниченная очередь сглаживает короткие серии импульсов энкодера; при очень быстром вращении очередь может переполниться и часть шагов потеряется. После подключения устройство отправляет короткое относительное движение мыши, пытаясь переместить указатель к краю. Скрытие курсора не гарантируется.

## Сборка

Используются проект Bruce для PlatformIO и заданные в нём версии платформы и библиотек. Установите Git, Python 3 и [PlatformIO Core](https://docs.platformio.org/en/latest/core/installation/index.html), затем выполните:

```sh
git clone --recurse-submodules https://github.com/andreychatgptac-sketch/bruce-scroller.git
cd bruce-scroller
git submodule update --init --recursive
python -m pip install platformio
pio run -e lilygo-t-embed-cc1101
```

Проверенное окружение — `lilygo-t-embed-cc1101`. Успешная сборка для него не означает поддержку других плат. При первой сборке скачиваются инструменты и библиотеки, это может занять время.

GitHub Actions проверяет сборку этой же платы при изменениях исходников и pull request. Workflow не собирает другие платы и не публикует релизные файлы.

## Установка и запуск

1. Сохраните нужные данные с устройства. Установка заменяет текущую прошивку.
2. Подключите **LILYGO T-Embed CC1101 (ESP32-S3)** по USB и найдите последовательный порт командой `pio device list`.
3. Загрузите прошивку для указанного окружения PlatformIO:

   ```sh
   pio run -e lilygo-t-embed-cc1101 -t upload --upload-port <PORT>
   ```

   Замените `<PORT>` на найденный порт, например `COM5` в Windows или `/dev/ttyACM0` в Linux. Загрузчик использует настройки разделов и флеш-памяти этой платы; не записывайте образ приложения по случайному адресу.
4. В Bruce откройте **Bluetooth → Bruce Scroller**.
5. На смартфоне выполните сопряжение с **Bruce Scroller** и проверьте управление в нужном приложении.
6. Нажмите боковую кнопку **Back**, чтобы выйти и вернуться в Bruce.

Если Android сохранил старую запись, удалите прежнее устройство Bruce HID в настройках Bluetooth и выполните сопряжение заново. Специальное Android-приложение для BLE HID не требуется, но действия в приложениях различаются.
