# App Examples

Various app examples with complete source code. Use these as starting points for your own apps.

---

## Example 1: Hello World

The simplest possible app. Displays a message and waits for ESC.

**`application.bam`**
```json
{
    "appid": "hello_world",
    "name": "Hello World",
    "version": "1.0",
    "author": "Bruce Team",
    "entry_point": "app_main"
}
```

**`app.c`**
```c
#include "bruce_api.h"

void app_main(BruceAPI* api) {
    if (!api) return;

    api->clear_screen(0x0000);
    api->draw_main_border_with_title("Hello World");
    api->draw_string("Welcome to Bruce!", 20, 60, 0xFFFF);
    api->draw_string("Press ESC to exit", 20, 90, 0xF800);

    while (!api->check_escape_press()) {
        api->bruce_delay(50);
    }
}
```

**Build and run:**
```bash
cd hello_world/
python /path/to/bbt.py build
# Copy dist/hello_world.bruce to SD card /apps/
```

## Example 2: Interactive Counter

Demonstrates input handling with NEXT/PREV buttons and dynamic screen updates.

**`application.bam`**
```json
{
    "appid": "counter",
    "name": "Counter App",
    "version": "1.0",
    "author": "Bruce Team",
    "entry_point": "app_main"
}
```

**`app.c`**
```c
#include "bruce_api.h"

void app_main(BruceAPI* api) {
    if (!api) return;

    int w = api->get_tft_width();
    int count = 0;
    char buf[32];

    api->clear_screen(0x0000);
    api->draw_main_border_with_title("Counter");
    api->draw_string("NEXT = +1", 20, 50, 0x07E0);
    api->draw_string("PREV = -1", 20, 70, 0x07E0);
    api->draw_string("ESC  = exit", 20, 90, 0xF800);

    while (1) {
        if (api->check_escape_press()) break;
        if (api->check_next_press()) count++;
        if (api->check_prev_press()) count--;

        // Clear counter area and redraw
        api->fill_rect(20, 120, w - 40, 30, 0x0000);
        api->bruce_log("Counter: %d\n", count);

        api->bruce_delay(100);
    }
}
```

## Example 3: Image Viewer

Demonstrates loading and displaying a compiled image asset.

**Directory structure:**
```
image_viewer/
├── application.bam
├── app.c
└── assets/
    └── logo.png        ← 64x64 pixel PNG
```

**`application.bam`**
```json
{
    "appid": "image_viewer",
    "name": "Image Viewer",
    "version": "1.0",
    "author": "Bruce Team",
    "entry_point": "app_main",
    "assets_dir": "assets"
}
```

**`app.c`**
```c
#include "bruce_api.h"
#include "bruce_assets.h"   // Auto-generated by bbt.py

void app_main(BruceAPI* api) {
    if (!api) return;

    int screen_w = api->get_tft_width();
    int screen_h = api->get_tft_height();

    api->clear_screen(0x0000);

    // Center the image on screen
    int x = (screen_w - logo_width) / 2;
    int y = (screen_h - logo_height) / 2;

    api->draw_image(x, y, logo_data, logo_width, logo_height);
    api->draw_string("Logo loaded from assets!", 10, 10, 0xFFFF);

    while (!api->check_escape_press()) {
        api->bruce_delay(50);
    }
}
```

## Example 4: Pixel Art Generator

Demonstrates `draw_pixel` and `bruce_random` for procedural graphics.

**`app.c`**
```c
#include "bruce_api.h"

void app_main(BruceAPI* api) {
    if (!api) return;

    int w = api->get_tft_width();
    int h = api->get_tft_height();

    api->clear_screen(0x0000);
    api->draw_string("Generating pixel art...", 10, 5, 0xFFFF);

    // Fill screen with random colored pixels
    for (int y = 20; y < h; y++) {
        for (int x = 0; x < w; x++) {
            uint16_t color = (uint16_t)(api->bruce_random() & 0xFFFF);
            api->draw_pixel(x, y, color);
        }
    }

    api->draw_string("Press ESC to exit", 10, 5, 0xFFE0);

    while (!api->check_escape_press()) {
        api->bruce_delay(50);
    }
}
```

## Example 5: Memory Stress Test

Demonstrates the memory quota system and garbage collector.

**`app.c`**
```c
#include "bruce_api.h"

void app_main(BruceAPI* api) {
    if (!api) return;

    api->clear_screen(0x0000);
    api->draw_main_border_with_title("Memory Test");

    // Allocate memory in 4KB chunks
    int allocations = 0;
    void* ptrs[20] = {0};

    for (int i = 0; i < 20; i++) {
        ptrs[i] = api->bruce_malloc(4096);  // 4KB each
        if (ptrs[i]) {
            allocations++;
            api->bruce_log("Allocated chunk %d at %p\n", i, ptrs[i]);
        } else {
            api->bruce_log("Allocation %d FAILED (quota reached)\n", i);
            break;
        }
    }

    api->bruce_log("Total allocations: %d (= %d KB)\n",
                   allocations, allocations * 4);
    api->draw_string("See Serial for results", 20, 60, 0x07E0);
    api->draw_string("Press ESC to exit", 20, 90, 0xF800);

    while (!api->check_escape_press()) {
        api->bruce_delay(50);
    }

    // Free some but deliberately "forget" others to test GC
    for (int i = 0; i < allocations / 2; i++) {
        api->bruce_free(ptrs[i]);
    }
    api->bruce_log("Freed %d chunks. The rest will be caught by GC.\n",
                   allocations / 2);
    // Firmware's Garbage Collector will free the rest on app exit
}
```

## Example 6: Using C++ and External Libraries

Demonstrates using C++ features and a third-party library.

**Directory structure:**
```
cpp_demo/
├── application.bam
├── app.cpp
└── libs/
    ├── tiny_json.c
    └── tiny_json.h
```

**`app.cpp`**
```cpp
#include "bruce_api.h"

extern "C" {
    // Entry point must have C linkage
    void app_main(BruceAPI* api);
}

// You can use C++ features
class Counter {
    int value_ = 0;
public:
    void increment() { value_++; }
    void decrement() { value_--; }
    int get() const { return value_; }
};

void app_main(BruceAPI* api) {
    if (!api) return;

    Counter counter;

    api->clear_screen(0x0000);
    api->draw_main_border_with_title("C++ Demo");

    while (1) {
        if (api->check_escape_press()) break;
        if (api->check_next_press()) counter.increment();
        if (api->check_prev_press()) counter.decrement();

        api->fill_rect(20, 60, 200, 30, 0x0000);
        api->bruce_log("Value: %d\n", counter.get());

        api->bruce_delay(100);
    }
}
```
