# Bruce Developer Docs

## Welcome to Bruce Developer Documentation!

---

This documentation is intended for developers interested in modifying the Bruce firmware, creating dynamically-loaded Apps (`.bruce` packages), or working on extensions for the platform.

If you are looking for general firmware usage, please visit the [Bruce Firmware README](../README.md) instead.

The documentation is divided into several sections:

- [Developer Tools](developer_tools.md) — Setting up your development environment
- [System Programming](system.md) — Understanding the firmware's internals
- [App Development](app_development.md) — Developing apps for Bruce
  - [BAP (Bruce App Package)](bruce_app_package.md) — Creating apps that can be dynamically loaded from the SD card
  - [BAM (Bruce App Manifest)](bruce_app_manifest.md) — How apps announce themselves to the system
  - [App Examples](app_examples.md) — Various app examples, complete with source code
- [API Reference](api_reference.md) — Complete SDK function reference
- [File Formats](file_formats.md) — Saving and loading data to and from files
- [Miscellaneous](misc.md) — Various useful pieces of information, FAQ, and troubleshooting
